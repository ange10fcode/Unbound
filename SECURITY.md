# Security policy

## Supported versions

Security fixes are applied to the latest release.

## Reporting a vulnerability

If the repository is hosted on GitHub, please use GitHub's **Private vulnerability reporting** / Security Advisory feature when available instead of opening a public issue.

Useful reports include:

- the affected Unbound version,
- Windows version and architecture,
- clear reproduction steps,
- expected vs. actual behavior,
- whether administrator privileges were involved.

Please do not include private files, credentials, or unrelated personal information in a report.
